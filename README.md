# Memory Game

A simple memory card game built with HTML, CSS and JavaScript.

## How to play

* The game starts automatically when the page loads.
* There are 16 cards containing 8 pairs.
* Click two cards to reveal them.
* If the cards match, they remain open.
* If they do not match, they are hidden again after a short delay.
* The game ends when all 8 pairs are found.
* The **New Game** button starts a new game with shuffled cards.

## Technologies

* HTML5
* CSS3
* JavaScript

## Deployment

The project is deployed using GitHub Pages.
